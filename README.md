### AgentAlign Lab &nbsp;·&nbsp; `terminal agents`

Preference learning pipeline for reliable terminal agents — structured trajectories, deterministic verifiers, DPO optimization, and held-out evaluation.

```
task suite → trajectories → preference pairs → DPO/LoRA → held-out eval
```

`task schemas` `verifiers` `trajectory logs` `chosen/rejected pairs` `LoRA` `eval dashboard`

→ **[Project detail](https://hey-shiv.github.io/projects/agentalign-lab/)**

### SvaraAlign Lab &nbsp;·&nbsp; `generative music`

Alignment system for raga-faithful AI music generation — symbolic verification, expert preference learning, reward modeling, and culturally grounded evaluation.

```
raga task → SvaraJudge → SvaraPrefs → SvaraReward → rerank + eval
```

`symbolic verification` `expert pairs` `reward modeling` `raga alignment` `reranking`

→ **[Project detail](https://hey-shiv.github.io/projects/svaraalign-lab/)**

## Work

- **[Cover Song Retrieval](https://hey-shiv.github.io/projects/cover-song-retrieval/)**: a two-stage system (learned encoder shortlist, then subsequence DTW rerank) that recognises the same song across key, tempo and voice. The first full run lost to plain classical alignment by 4.5×; three more runs closed the gap to 1.11×. Still below published systems, and the write-up says so. [Repo](https://github.com/hey-shiv/cover-version-retrieval) · [Live site](https://cover-version-retrieval.vercel.app/)
- **[Coil](https://hey-shiv.github.io/projects/vcp-screener/)**: a screener over 2,300 NSE stocks paired with a ten-year point-in-time backtest built to disprove it. The pattern returned 11.0% CAGR against 22.3% for random entries, so it found no edge. [Live app](https://coil-vcp.vercel.app)
- **[Modern Mini LLM](https://github.com/hey-shiv/mini-modern-llm)**: a small transformer on TinyStories with RMSNorm, rotary embeddings, grouped-query attention, SwiGLU and its own BPE tokenizer.
- **[Audio Explorer](https://github.com/hey-shiv/Audio-Explorer)**: an app that makes the audio-ML front end inspectable (STFT, Mel spectrograms, MFCCs, beat tracking).
